## 실행 확인

| 환경 | 확인한 내용 |
|---|---|
| Windows PowerShell 5.1.26100.9168 | 설치·재설치, 공백/작은따옴표 설치 경로, 기존 프로필 보존, 한글/공백 파일, 숨김 포함/제외, 제외 폴더, 디렉터리 유지, 제거 시 이후 수정 보존, 첫 프로필 바이트 단위 복원 |
| PowerShell 7.6.5 | 위와 동일 |
| Kali Bash | 설치·재설치, 공백/작은따옴표 설치 경로, 설정 로드, 파일 검색, 숨김 포함/제외, 제외 폴더, 제거·원본 복원 |
| Zsh 5.9.2 (임시 패키지 실행) | 설치·재설치, 공백/작은따옴표 설치 경로, 기존 설정 보존, 한글/공백 파일, 숨김 포함/제외, 기록 검색, Ctrl+R/T 위젯 등록, 제거·원본 복원 |

Windows 도구: fzf 0.74.2 / fd 10.4.2 / bat 0.26.1.
Kali 도구: fzf 0.74.3 / fd 10.5.0 / bat 0.26.1.

테스트는 별도 프로필·설치 경로와 이미 설치된 의존성을 사용했다. WinGet/apt의 신규 설치 분기, 모든 터미널의 키 충돌·실제 UI 렌더링은 이 자동 테스트에서 검증하지 않았다. 파일 선택은 fzf의 비대화형 필터를 사용했다.

Zsh는 다운로드한 패키지를 임시 폴더에 풀어 실행했다. 모듈 경로를 테스트 환경에만 지정했으며, 시스템 기본 셸과 사용자 프로필은 변경하지 않았다. 실제 키 입력과 미리보기 UI 검증 범위는 위 제한과 같다.

## 기존 스크린샷 판독

블로그 원본 스크린샷을 기준으로 설명했다. 이 프로젝트가 생성한 신규 실행 증적은 아니다.

1. **usage-screenshot-01.png**: Kali에서 `fh` 실행, 검색어 `install`, 설치 명령 기록 목록. 선택 후 입력줄 삽입·자동 실행 여부, Bash/Zsh 여부는 화면만으로 판단할 수 없다.
2. **usage-screenshot-02.png**: Windows 사용자 홈에서 `ff` 실행, 상대 파일 경로 목록. 선택된 `Searches/winrt--...` 파일의 XML을 오른쪽에 표시한다. 모든 후보가 숨김 제외 조건을 충족하는지까지 화면만으로 검증할 수 없다.
3. **usage-screenshot-03.png**: `cd /` 후 `ff`, 검색어 `/usr/share/word`. `/usr/share/dirb/wordlists/big.txt` 선택. 오른쪽의 `.bashrc`·`.ssh` 등은 워드리스트 문자열이며 실제 사용자 설정 내용을 보여주는 것이 아니다.
4. **usage-screenshot-04.png**: `ff C:\Pentest\02_Tools\Wordlists\SecLists-master\` 실행. 선택된 경로는 `Pattern-Matching` 아래이며 끝 파일명은 잘려 있다. 오른쪽 `api_key`, `secret_key`, `token`은 파일의 패턴 문자열이며 탐지된 비밀값이 아니다.

화면에 없는 기능을 캡처의 결과로 설명하지 않는다. 원본 스크린샷은 사용자의 요청에 따라 `docs/images/`에 포함했다.
